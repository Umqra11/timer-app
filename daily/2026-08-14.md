## ⚠️ Lessons Learned (Sprint-06)

1. **Atomic commit per task** — 11 commit (her biri geri alınabilir, smoke test bağımsız). Production deploy ile birleştirildiğinde güvenli.
2. **TDD source-grep pattern** — projede `vi.useFakeTimers()` YOK, regex-based test convention hakimiyet. P2 heartbeat + P3 tick refactor + F7 N+1 fix hepsi bu pattern'de test edildi.
3. **M0-fix serisi** D-079 DECISIONS'a alındı — emergency debug tekrarını önlemek için institutional memory.
4. **Plan'daki DECISIONS numara kontrolü** — D-063/D-064 ZATEN DOLU uyarısı Sprint-06 Faz 3 P4'te tespit edildi. **Kural:** Plan yazılmadan önce DECISIONS.md son numara kontrol edilmeli.
5. **vue-pomo `createPersistedState` → IndexedDB pattern** (F7) — svelte-persisted-store localStorage = YANLIŞ, async gerekli. `idb-keyval` (~600 byte) ideal.
6. **Callable vs trigger** (F3) — sahiplik kontrolü delete'ten ÖNCE yapılmalı, trigger zaten silinmiş doc'u görür. Callable kararı doğru.
7. **Pure $derived > Rust state machine** (P3, D-077) — Pomotroid yaklaşımı Tauri/masaüstü için, SvelteKit PWA için pure function + reactive state yeterli.
8. **No-badge policy enforcement** (T5, D-069) — patron'un kesin "istemiyorum" kararı. Sprint-08+'da gamification geri alma niyeti YOK.
