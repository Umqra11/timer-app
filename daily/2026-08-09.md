### v11 — 5 iyileştirme/dokümantasyon (yerel, commit bekliyor)

1. **`presence.ts:48`** — `console.log('[presence] no db')` kaldırıldı (sessiz return). Production'da debug log, offline modda spam yapıyordu. `client.ts:44` zaten "running in offline mode" uyarısı veriyor.

2. **`firestore.rules:38-55`** — `/users/{uid}/rateLimit/{doc}` structure validation:
   - `hasAll(['minuteCount', 'minuteResetAt', 'hourCount', 'hourResetAt'])`
   - Tüm alanlar `is int`
   - `minuteCount >= 0`, `hourCount >= 0`
   - `delete: if false`
   
   Malformed/negatif yazımlar reddedilir. Cross-user yazım koruması mümkün değil (D-015 — auth yok), Cloud Function ile (Sprint-04 #6).

3. **`reactions.ts:128-133`** — `expireAt` client/server clock trade-off dokümante:
   - Client-side `Date.now() + REACTION_TTL_MS`
   - Firestore TTL server clock kullanır, ±1 sn NTP skew olur
   - 4 saatlik pencere için tolere edilebilir
   - Gerçek server-time için Cloud Function onWrite gerekli

4. **`+page.svelte:184-189`** — `reactionsFor` perf trade-off dokümante:
   - MVP'de tüm oda tepkileri tek subscribe + client filter
   - 10+ kişi / 100+ tepki ölçeğinde `where('targetUid', 'in', memberUids)` ile server-side filter tercih edilmeli (Firestore `in` 30 değer destekler)
   - Şu an premature optimization

5. **`reactions.ts:104-118`** — Rate limit race condition comment netleştirildi:
   - Aynı uid'den iki eşzamanlı istek aynı sayacı +1 yapabilir
   - Atomic tx için server-side `runTransaction` (server-side async `getDoc` sorunu yok)
   - Sprint-04 #6 (Cloud Function)
